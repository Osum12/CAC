# Council Lens

Council Lens helps Georgia residents see what their local government is working on: meetings, proposals and public documents in plain language, with links back to the official source.

A student project for the Congressional App Challenge 2026. Civic records currently cover the Fulton County Board of Commissioners.

## Quick start

The app is in `Alpharetta_Civic_App_Team_Pack/`. It needs Node.js 22.12 or newer and npm.

```bash
cd Alpharetta_Civic_App_Team_Pack
npm ci
npm run dev          # opens on http://localhost:5173
```
